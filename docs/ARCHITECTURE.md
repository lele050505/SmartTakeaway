## 2. 核心比价算法与费用结构

不同平台的报价并非简单的“标价对比”，而是多维度费用的综合运算：

$$\text{最终预估到手价 (Final Price)} = \text{商品标价} - \text{店铺满减} - \text{红包/券抵扣} + \text{配送费} + \text{包装费}$$

### 平台特征差异：
1. **美团外卖 (`meituan_waimai`)**：
   - 餐饮正餐供给丰富，神券体系减免大；
   - 美团专送配送费一般在 3.0 ~ 5.0 元，包装费标准 1.0 ~ 2.0 元。
2. **饿了么 (`eleme`)**：
   - 超级吃货红包与百亿补贴力度大；
   - 蜂鸟即配配送费约 2.5 ~ 4.0 元。
3. **美团闪购 (`meituan_shangou`)**：
   - 主打 24 小时即时零售、超市便利、冷饮、日常百货；
   - 包装费通常较低（0.5 ~ 1.0 元），且常有秒杀特价。
4. **淘宝闪购 (`taobao_shangou`)**：
   - 淘鲜达、天猫超市半日达、淘菜闪购；
   - 淘金币抵扣叠加，配送时间快。
